# Loan Default Risk Prediction

## Overview

This project predicts whether a borrower is likely to default on a loan using Machine Learning models.

Dataset Source:
https://www.kaggle.com/datasets/ninzaami/loan-predication

---

## Business Problem

Banks and financial institutions need to identify risky borrowers before approving loans. This project helps analyze applicant profiles and estimate default risk.

---

## Workflow

1. Data Loading
2. Exploratory Data Analysis (EDA)
3. Missing Value Handling
4. Feature Encoding
5. Feature Scaling
6. Model Training
7. Model Evaluation
8. Feature Importance Analysis

---

## Models Used

- Logistic Regression
- Random Forest Classifier
- Gradient Boosting Classifier

---

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

## Key Insights

- Income and Credit History strongly influence loan approval.
- Gradient Boosting improves predictive performance.
- Feature engineering significantly improves model quality.
